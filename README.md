# Bayesian Credit Risk Analysis

## Overview

This project focuses on credit risk analysis using a hierarchical Beta-Binomial Bayesian model and Monte Carlo simulation.

The objective is to estimate and compare credit risk across different groups using Bayesian inference and simulation techniques.

## Methods

* Bayesian inference
* Hierarchical Beta-Binomial model
* Monte Carlo simulation
* Posterior probability estimation
* Credit risk comparison

## Project Structure

* `bayesian_credit_risk.ipynb` — Main Jupyter Notebook containing the analysis, calculations, simulations, and results.

## Tools & Technologies

* Python
* Jupyter Notebook
* NumPy
* Pandas
* SciPy
* Matplotlib
